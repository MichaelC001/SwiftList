# 初始面板

搜尋框為空時，快速視窗結果列表上方顯示的一個標籤欄，不用輸入查詢就能快速訪問最近檔案、收藏夾和歷史記錄。

- **啓用初始面板** —— 總開關;關閉後，不管下面各個標籤自己的設定如何，整個面板都不會激活。

四個子標籤:**最近檔案**、**上次目錄**、**插件標籤** 和 **標籤順序**。

## 最近檔案

- **啓用面板** —— 勾選框;搜尋框為空時顯示該標籤。
- **目錄** —— 要監控的資料夾，每行一個(添加/編輯/刪除單行，以及批量文本編輯，和[排除規則列表](./index-drives#排除規則)是同一套交互)。可以是本地磁碟機、已掛載的網絡磁碟機，以及 WSL 路徑(`\\wsl$\...` 或 `\\wsl.localhost\...`)——會匹配到你已經在[索引](./index-drives)裏配置並建過索引的對應條目。
- **顯示的檔案數量上限** —— 範圍 1–100，預設 10。
- **時間範圍(分鐘)** —— 只有在這個時間範圍內修改過的檔案才符合條件，疊加在上面的數量上限之上。範圍 1–43200(30 天)，預設 60。

只列檔案，不列資料夾：往一個資料夾裏加東西、刪東西都會刷新它自己的修改時間，所以正在用的目錄裏，資料夾總是「最新」的那幾個，會把這份清單本來要顯示的東西擠下去。

每一項的第二行開頭會帶上一個相對時間——"X 秒/分鐘/小時/天前"——直接根據索引裏已經存好的檔案最後修改時間算出來，不需要額外訪問磁碟。小時和天這兩檔在餘下的分鐘/小時為 0 時會省略(比如顯示
"2小時前"而不是"2小時0分鐘前")。

## 上次目錄

- **啓用面板** —— 勾選框，預設開啓。

顯示 SwiftList 接管系統檔案打開/保存對話方塊時，最後停留過的目錄內容——不用記路徑，就能快速回到剛才用檔案選擇器瀏覽過的地方。真正的索引會用到的隱藏/系統檔案過濾和[排除規則](./index-drives#排除規則)在這裏同樣生效，所以不會出現 `$RECYCLE.BIN` 這類東西。本次運行還沒有觸發過、該目錄已經不存在、或者就是桌面(經常只是預設落腳點，不算真的"去過")時，這個標籤完全不會出現。

## 插件標籤

插件提供的標籤(如歷史記錄、收藏夾)在面板裏各自帶一個 **×** 按鈕，可以先把它隱藏起來。這只是面板本地的"先不顯示"選擇——和在[插件](./plugins)頁面裏把該插件組件本身禁用是兩回事，後者是讓它徹底不參與使用。通過 × 關閉的標籤會按提供它的插件分組顯示在這裏，未勾選;勾上即可重新打開。

只有插件層面已啓用的標籤才會出現在這個列表裏——在[插件](./plugins)頁面整體禁用的組件，從一開始就不會成為候選標籤。

## 標籤順序

跟設定裏其它地方(見[收藏夾](./favorites))同一套上移/下移(也可以拖動)排序列表，但管的是整個面板標籤欄——
內置的兩個標籤(最近檔案、上次目錄)和所有當前可見的插件標籤都在同一個扁平列表裏，跟上面按插件分組的"插件標籤"不一樣。把某個標籤上移或下移，就能改變它在實際面板裏的位置；這個列表裏從上到下的順序，對應面板裏從左到右的順序。

這裏只列出當前真的會顯示出來的標籤——上面被關掉的"最近檔案"/"上次目錄"，或者用 **×** 按鈕關閉過的插件標籤，在重新啓用/重新打開之前都沒有順序可調。
