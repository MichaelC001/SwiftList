# 快速面板

由熱鍵呼出、停靠在當前前景視窗右下角的浮動面板，尺寸為該視窗的一半高、一半闊。它按你指定的資料夾顯示內容——縮圖平鋪或明細清單——讓你不必離開正在工作的視窗就能取用檔案、把檔案拖出去，或者把檔案拖進來。拖動它的頂部區域可以在本次呼叫期間把它挪到別處。

- **啟用快速面板** — 總開關；關掉之後熱鍵不再有任何反應。

呼出它的按鍵在[熱鍵](./hotkeys-page)頁面上(預設 `Ctrl+F2`)。

## 工作區

面板一次只顯示一個**工作區**，每個工作區就是標籤欄裏的一個標籤。工作區是為某一類工作湊起來的一組來源——某個項目的幾個資料夾、放參考資料的地方、專門往裏丟東西的收件箱。

左側清單就是工作區本身，配有**新增工作區**、**複製工作區**、**刪除工作區**按鈕，以及設定裏其他地方同樣的上下箭頭(或拖動)排序清單(參見[我的最愛](./favorites))。這裏的從上到下，就是面板標籤欄裏的從左到右。

- **名稱** — 標籤上顯示的文字。留空則回落到一個帶翻譯的預設名，所以從沒改過名的工作區會跟隨介面語言。
- **啟用** — 每個工作區旁邊的核取方塊。關掉之後工作區的設定還在，但不再有標籤，適合那些這個月用不上、刪掉又得重新搭一遍來源清單的工作區。面板裏標籤上的 **×** 做的就是這件事，所以要重新打開得回到這裏。

選中的工作區透過三個子標籤編輯：**來源**、**插件來源**、**應用程式**。

## 來源

每個來源就是面板裏的一個分組，按這個清單的順序顯示。**新增資料夾**用來加入；每行前面的核取方塊可以隱藏該分組而不刪除它；名稱框用來覆蓋分組標題(留空則用資料夾自己的名字)；**更多選項**裏是其餘設定：

- **顯示** — 這個分組從資料夾裏取甚麼：
  - **最近變動的檔案** — 只取最近有變動的，最新在前，由索引回答而不是去走訪資料夾。
  - **全部，最新在前** — 不會因為時間久就隱藏檔案，只決定誰排在前面。
  - **全部，按名稱** — 把資料夾當捷徑欄用。
- **資料夾** — 資料夾本身，旁邊的 **…** 按鈕可以瀏覽選擇。
- **包含子資料夾** — 預設關閉。
- **接受拖入的檔案** — 拖到這個分組上的檔案和資料夾，會被複製進它的資料夾，走 Windows 自己的檔案複製(它的進度對話框、它的衝突提示、它的復原)。永遠是複製，不會是移動。預設關閉，而且是逐個來源分別設定的：當收件箱用的資料夾需要它，而只讀不寫的資料夾不需要。
- **檔案** — 一條或多條萬用字元，用 `;` 或 `,` 分隔(例如 `*.mp4;*.mkv`)。資料夾一律顯示。
- **最多** — 這個分組最多顯示幾條。0 表示來源裏有多少顯示多少。
- **變動於(分鐘內)** — 只有這段時間內有變動的項目才算數。0 表示不限時間。
- **以清單顯示** — 這個分組以明細清單而不是縮圖平鋪打開。哪種更合適是資料夾自己的屬性：圖片適合平鋪，文件適合看名稱和日期。

## 插件來源

由插件提供的來源。勾選一個就把它加進當前工作區，之後它會出現在**來源**清單裏，和資料夾並排，排序、改名、隱藏的方式完全一樣。CoreExtensions 自帶兩個：**Windows 歷史記錄**(系統自己的最近使用文件清單，已解析成它指向的真實檔案，最新在前)和**我的最愛**(你的[我的最愛](./favorites)，按你排好的順序)。

加不加是一次性的決定，所以它和負責排序、改名的那個清單分成了兩個標籤。清單裏只會出現插件組件在[插件](./plugins)頁面處於啟用狀態的來源。插件沒了的 id 會保留原位而不是被清掉，所以關掉一週的插件回來時還在你放它的地方。

## 應用程式

這個工作區歸屬的應用程式，每行一個處理程序名稱(`chrome` 或 `chrome.exe` 都行)。在其中任一個上面呼出面板，它就會開在這個工作區，而不是停在上次的位置——你正身處的應用程式本身已經說明了你指的是哪一組資料夾。留空則這個工作區只能手動切過去。

## 僅快速面板

面板不去打擾的應用程式，每行一個處理程序名稱。它是**疊加**在全域[處理程序黑名單](./hotkeys-page#process-blacklist)之上而不是取代它：全域擋掉的在這裏同樣被擋掉。這份名單是給那些只有這個面板才有理由避開的應用程式準備的——它會把自己貼到前景視窗上，所以全螢幕播放器或遊戲會被它毀掉，但這些應用程式並不至於要進全域黑名單。

## 使用面板

- **篩選框** — 在標籤欄右側，面板一打開就有焦點。它做的是模糊匹配(和搜尋視窗同一套 fzf 模式匹配，含拼音別名)，範圍僅限當前工作區。篩選期間沒有任何符合項目的分組會被隱藏。
- **Enter** 打開選中項，和雙擊等效。第一條從一開始就是選中的，所以一次呼叫可以在篩選框裏「打字然後 Enter」一氣呵成，全程不用離開輸入框。
- **切換工作區** — 按住「跳到第 N 條結果」的修飾鍵(預設 `Ctrl`，見[熱鍵](../hotkeys))再按 1–9，或者直接點標籤。標籤可以拖動改順序，每個標籤上的 **×** 會關掉對應工作區。關掉最後一個時，面板本身也會關閉。
- **分組標題**上有排序開關(按名稱／按修改日期)、檢視開關(平鋪／清單)和摺疊箭頭。你在這裏做的調整在面板打開期間一直有效；起始狀態由上面的設定決定。
- **多選** — 平鋪檢視下，在空白處拖出一個框即可框選。選取狀態屬於某一個分組，因為每個分組各畫各的清單；點擊空白處會取消選取。
- **拖入檔案** — 檔案、資料夾，或者直接從網頁上拖一張圖片，丟到允許拖入的分組上即可。只要拖動本身能提供檔案，就都收，不只是圖片。複製完成後該分組會自動重新載入。
- **不讓它消失** — 面板失去焦點時會關閉。「釘住」按鈕，或者「保持視窗不消失」熱鍵(預設 `Ctrl+T`，和快速視窗用的是同一個)，可以在本次呼叫期間暫停這個行為。
- **Esc** 在篩選框有內容時先清空它，否則關閉面板。
- 面板會讓自己保持最新：正在顯示的資料夾在磁碟上發生變化時會重新載入，走的是全應用統一的、基於索引的監聽，而不是自己再掃一遍。
