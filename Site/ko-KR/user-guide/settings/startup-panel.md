# 시작 패널

검색 상자가 비어 있을 때마다 퀵 창의 결과 목록 위에 표시되는 탭 스트립으로, 쿼리를 입력하지 않고도
최근 파일, 즐겨찾기, 기록에 빠르게 접근할 수 있게 해줍니다.

- **시작 패널 활성화** — 마스터 스위치입니다. 꺼져 있으면 아래의 탭별 설정과 무관하게 패널이 전혀
  활성화되지 않습니다.

네 개의 하위 탭: **최근 파일**, **마지막 디렉터리**, **플러그인 탭**, **탭 순서**입니다.

## 최근 파일

- **패널 활성화** — 체크박스, 검색 상자가 비어 있을 때 탭을 보여줍니다.
- **디렉터리** — 감시할 폴더를 한 줄에 하나씩 지정합니다([제외 규칙](./index-drives#제외-규칙)과
  동일한 행 추가/편집/삭제 및 일괄 텍스트 편집). 로컬 드라이브, 매핑된 네트워크 드라이브, WSL
  경로(`\\wsl$\...` 또는 `\\wsl.localhost\...`)를 포함할 수 있으며, [인덱스](./index-drives)에서 이미
  구성하고 인덱싱해 둔 것과 매칭됩니다.
- **표시할 최대 파일 수** — 범위 1~100, 기본값 10.
- **시간 범위 (분)** — 위의 개수 제한에 더해, 현재로부터 이 분 이내에 수정된 파일만 대상이 됩니다.
  범위 1~43200(30일), 기본값 60.

파일만 나오고 폴더는 나오지 않습니다: 폴더 자신의 수정 시각은 안에 무언가가 더해지거나 빠질 때마다
바뀌므로, 작업 중인 디렉터리에서는 폴더가 늘 "가장 최근" 축에 끼어 이 목록이 정작 보여 주려는 것을
밀어냈습니다.

각 항목의 두 번째 줄에는 상대 시간("X초/분/시간/일 전")이 접두사로 붙으며, 이는 인덱스에 이미 저장된
해당 파일의 마지막 수정 타임스탬프로부터 만들어지므로 추가적인 디스크 접근 비용이 들지 않습니다.
시간과 일 단위는 값이 0일 때 더 작은 단위를 생략합니다(예: "2시간 0분 전" 대신 "2시간 전").

## 마지막 디렉터리

- **패널 활성화** — 체크박스, 기본값 켜짐.

SwiftList 자체의 대화상자 가로채기 기능이 활성화되어 있는 동안 네이티브 파일 열기/저장 대화상자가
마지막으로 이동했던 폴더의 내용을 보여줍니다 — 경로를 기억할 필요 없이 방금 파일 선택기로 탐색하던
곳으로 빠르게 돌아가는 방법입니다. 실제 인덱스에 적용되는 것과 동일한 숨김/시스템 파일 필터링과
[제외 규칙](./index-drives#제외-규칙)이 여기에도 적용되므로, `$RECYCLE.BIN` 같은 것은 나타나지
않습니다. 이번 세션에서 아직 그런 일이 일어나지 않았거나, 폴더가 더 이상 존재하지 않거나, 그것이
바탕 화면이라면(너무 자주 그저 기본 도착 지점일 뿐 실제 탐색 대상이 아니므로) 이 탭은 전혀 나타나지
않습니다.

## 플러그인 탭

플러그인이 제공하는 탭(예: 기록, 즐겨찾기)은 각각 실시간 패널에서 지금 당장 숨기기 위한 **×** 버튼을
가지고 있습니다. 이는 패널 한정 "숨기기" 선택으로, [플러그인](./plugins)에서 컴포넌트 자체를
비활성화하여 아예 사용되지 않게 하는 것과는 별개입니다. 이런 방식으로 닫힌 탭은 그것을 제공하는
플러그인별로 그룹화되어 여기에 체크 해제된 상태로 나열됩니다 — 체크하면 다시 나타납니다.

이 목록에는 플러그인 컴포넌트가 현재 활성화된 탭만 나열됩니다 — [플러그인](./plugins)에서 완전히
비활성화된 것은 애초에 탭 후보가 되지 않습니다.

## 탭 순서

설정의 다른 곳에서 사용하는 것과 동일한 위/아래 화살표(또는 드래그하여 재정렬) 목록입니다
([즐겨찾기](./favorites) 참고). 다만 이는 위의 플러그인 탭이 플러그인별로 그룹화하는 것과 달리, 패널의
탭 스트립 전체 — 내장 탭(최근 파일, 마지막 디렉터리)과 현재 보이는 모든 플러그인 탭 — 를 하나의 평평한
목록으로 다룹니다. 탭을 위나 아래로 옮기면 다른 것들에 비해 어디에 자리 잡을지가 바뀝니다. 이 목록의
왼쪽에서 오른쪽 순서가 실시간 패널의 왼쪽에서 오른쪽 순서입니다.

지금 실제로 표시될 탭만 나열됩니다 — 위에서 비활성화한 최근 파일/마지막 디렉터리 탭이나, **×**
버튼으로 닫힌 플러그인 탭은 다시 활성화되거나 다시 열리기 전까지는 정렬할 것이 없습니다.
