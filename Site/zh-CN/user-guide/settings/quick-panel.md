# 快速面板

由热键呼出、停靠在当前前台窗口右下角的浮动面板，尺寸为该窗口的一半高、一半宽。它按你指定的文件夹显示内容——缩略图平铺或明细列表——让你不必离开正在工作的窗口就能取用文件、把文件拖出去，或者把文件拖进来。拖动它的顶部区域可以在本次召唤期间把它挪到别处。

- **启用快速面板** — 总开关；关掉之后热键不再有任何反应。

呼出它的按键在[热键](./hotkeys-page)页面上(默认 `Ctrl+F2`)。

## 工作区

面板一次只显示一个**工作区**，每个工作区就是标签栏里的一个标签。工作区是为某一类工作攒起来的一组来源——某个项目的几个文件夹、放参考资料的地方、专门往里丢东西的收件箱。

左侧列表就是工作区本身，配有**新建工作区**、**复制工作区**、**删除工作区**按钮，以及设置里其他地方同样的上下箭头(或拖动)排序列表(参见[收藏夹](./favorites))。这里的从上到下，就是面板标签栏里的从左到右。

- **名称** — 标签上显示的文字。留空则回落到一个带翻译的默认名，所以从没改过名的工作区会跟随界面语言。
- **启用** — 每个工作区旁边的复选框。关掉之后工作区的配置还在，但不再有标签，适合那些这个月用不上、删掉又得重新搭一遍来源列表的工作区。面板里标签上的 **×** 做的就是这件事，所以要重新打开得回到这里。

选中的工作区通过三个子标签编辑：**来源**、**插件来源**、**应用**。

## 来源

每个来源就是面板里的一个分组，按这个列表的顺序显示。**添加文件夹**用来添加；每行前面的复选框可以隐藏该分组而不删除它；名称框用来覆盖分组标题(留空则用文件夹自己的名字)；**更多选项**里是其余设置：

- **显示** — 这个分组从文件夹里取什么：
  - **最近改动的文件** — 只取最近有变动的，最新在前，由索引回答而不是去遍历文件夹。
  - **全部，最新在前** — 不会因为时间久就隐藏文件，只决定谁排在前面。
  - **全部，按名称** — 把文件夹当快捷方式栏用。
- **文件夹** — 文件夹本身，旁边的 **…** 按钮可以浏览选择。
- **包含子文件夹** — 默认关闭。
- **接受拖入的文件** — 拖到这个分组上的文件和文件夹，会被复制进它的文件夹，走 Windows 自己的文件复制(它的进度对话框、它的冲突提示、它的撤销)。永远是复制，不会是移动。默认关闭，并且是逐个来源单独设的：当收件箱用的文件夹需要它，而只读不写的文件夹不需要。
- **文件** — 一条或多条通配符，用 `;` 或 `,` 分隔(例如 `*.mp4;*.mkv`)。文件夹始终显示。
- **最多** — 这个分组最多显示多少条。0 表示来源里有多少显示多少。
- **改动于(分钟内)** — 只有这段时间内有改动的条目才算数。0 表示不限时间。
- **以列表显示** — 这个分组以明细列表而不是缩略图平铺打开。哪种更合适是文件夹自己的属性：图片适合平铺，文档适合看名字和日期。平铺时把一行**平分**给五个——所以面板停靠在宽窗口上时，得到的是值得一看的大缩略图，而不是更多的小图。五不是死数：宽到连五个都比缩略图能填满的还宽时，一行就多放几个；窄到放不下五个还看得清时，就少放几个。无论几个，一行都是**平分**而不是按固定尺寸摆放，所以行尾永远不会空出一块。每张图保持自己的比例，所以一整个文件夹的 16:9 视频不会变成一格格竖着的方框、每格上下各空一条。

在这里添加的文件夹，默认是**全部内容，按名称排序**——手动挑一个文件夹进来，多半是因为里面存着东西。全新安装自带的那个工作区是例外，而且是有意的：桌面、下载、文档是东西「到达」的地方，所以默认按最近改动的文件显示。

## 插件来源

由插件提供的来源。勾选一个就把它加进当前工作区，之后它会出现在**来源**列表里，和文件夹并排，排序、改名、隐藏的方式完全一样。CoreExtensions 自带三个：**Windows 历史记录**(系统自己的最近使用文档清单，已解析成它指向的真实文件，最新在前)、**历史记录**(你通过 SwiftList 自己打开过的东西，最近的在前——这是另一份清单，而且只有它会包含应用程序)和**收藏夹**(你的[收藏夹](./favorites)，按你排好的顺序)。

添加与否是一次性的决定，所以它和负责排序、改名的那个列表分开成了两个标签。列表里只会出现插件组件在[插件](./plugins)页面处于启用状态的来源。插件没了的 id 会保留原位而不是被清掉，所以关掉一周的插件回来时还在你放它的地方。

## 应用

这个工作区归属的应用，每行一个进程名(`chrome` 或 `chrome.exe` 都行)。在其中任意一个上面呼出面板，它就会打开到这个工作区，而不是停在上次的位置——你正身处的应用本身已经说明了你指的是哪一组文件夹。留空则这个工作区只能手动切过去。

## 仅快速面板

面板不去打扰的应用，每行一个进程名。它是**叠加**在全局[进程黑名单](./hotkeys-page#process-blacklist)之上而不是取代它：全局挡掉的在这里同样被挡掉。这份名单是给那些只有这个面板才有理由避开的应用准备的——它会把自己贴到前台窗口上，所以全屏播放器或游戏会被它毁掉，但这些应用并不至于要进全局黑名单。

## 使用面板

- **筛选框** — 在标签栏右侧，面板一打开就有焦点。它做的是模糊匹配(和搜索窗口同一套 fzf 模式匹配，含拼音别名)，范围仅限当前工作区。筛选期间没有任何匹配项的分组会被隐藏。
- **回车**打开选中项，和双击等效。第一条从一开始就是选中的，所以一次召唤可以在筛选框里「打字然后回车」一气呵成，全程不用离开输入框。
- **上下方向键**移动选中项，并且到了一个分组的最后一行不会停下，而是跨进下一个分组——所有分组从上到下就是一整份列表。在筛选框里也能用，且不会把焦点从框里抢走，所以「筛」和「选」是同一串动作。以缩略图平铺显示的分组内部，仍然按网格一行一行地走。设置里的「选择下一项／上一项」热键(默认 `Ctrl+N`／`Ctrl+P`)效果相同；但如果有插件动作绑在同一个键上，动作优先。
- **切换工作区** — 按住「跳转到第 N 条结果」的修饰键(默认 `Ctrl`，见[热键](../hotkeys))再按 1–9，或者直接点标签。标签可以拖动改顺序，每个标签上的 **×** 会关掉对应工作区。关掉最后一个时，面板本身也会关闭。
- **分组标题**上有排序开关(按名称／按修改日期)、视图开关(平铺／列表)和折叠箭头。你在这里做的调整在面板打开期间一直有效；初始状态由上面的设置决定。
- **多选** — 平铺视图下，在空白处拖出一个框即可框选。选中状态属于某一个分组，因为每个分组各画各的列表；点击空白处会取消选中。
- **拖入文件** — 文件、文件夹，或者直接从网页上拖一张图片，扔到允许拖入的分组上即可。只要拖动本身能提供文件，就都收，不只是图片。复制完成后该分组会自动重新加载。
- **预览** — 按 QuickLook 那个键(默认 `Alt+P`，和其他热键一样可以在[热键](./hotkeys-page)页面改)，为选中的文件打开预览窗口，之后它会跟着选中项走。它停靠在面板右侧；右侧被屏幕边缘挤得放不下时，才翻到左侧——面板贴在最大化窗口的右下角时就是这种情况。点进预览窗口不会让面板消失；两个都点开才会。面板关闭时它一起关。
- **不让它消失** — 面板失去焦点时会关闭。「钉住」按钮，或者「保持窗口不消失」热键(默认 `Ctrl+T`，和快速窗口用的是同一个)，可以在本次召唤期间挂起这个行为。
- **Esc** 在筛选框有内容时先清空它，否则关闭面板。
- 面板会让自己保持最新：正在显示的文件夹在磁盘上发生变化时会重新加载，走的是全应用统一的、基于索引的监听，而不是自己再扫一遍。
